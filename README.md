# 白酒计算器（手机端）

给终端客户快速算「底价」的单页应用：录入拿货与赠送产品 → 自动分摊出每个产品的底价 → 自动验算总数量 × 底价是否等于客户付款 → 一键生成可发给客户的对账单长图。

- **单文件、零依赖、可离线**：全部代码在 `index.html` 内，不需要联网、不需要安装、不需要服务器。
- **数据存本机**：产品库与计算记录保存在浏览器本地（localStorage），刷新不丢，可导出 JSON 备份。

## 一、快速开始

### 方式 1：电脑上直接用
双击 `index.html`（推荐 Chrome / Edge / Safari）。

### 方式 2：手机上用（最常用）
1. 手机连上和电脑**同一个 Wi-Fi**
2. **双击** `启动手机访问.command`（首次可能要在「系统设置 → 隐私与安全性」里允许运行）
3. 窗口里会显示地址，例如 `http://192.168.101.121:8080`，用手机浏览器打开即可
4. 手机浏览器菜单里选「**添加到主屏幕**」，以后点图标就能直接当 App 用

也可以手动启动（等价）：

```bash
cd 底价计算器
python3 -m http.server 8080
# 手机浏览器打开 http://电脑的局域网IP:8080
# Mac 查 IP：ipconfig getifaddr en0
```

> 打不开先检查三点：① 手机和电脑是否同一个 Wi-Fi；② 路由器是否开了「访客网络 / AP 隔离」；③ macOS 防火墙弹窗是否点了「允许」。
> 服务只在电脑开机且窗口没关时有效，手机数据存在手机浏览器本地，不受影响。

### 方式 2b：不想开电脑
把 `index.html` 用微信/QQ 发到手机，用手机浏览器打开；或上传到任意静态托管（见方式 3），地址固定、随时可用。

### 方式 3：放到静态托管
把 `index.html` 上传到任意静态托管（公司内网、GitHub Pages、Netlify、对象存储等），手机随时打开。

## 三、底价计算规则（核心）

设客户实际付款为 **P**（默认等于拿货合计金额，也可手动指定抹零/扣减后的金额）：

1. **拿货金额** ＝ Σ（开票价 × 规格 ÷ 箱 × 箱数）
2. **赠送货值** ＝ Σ（开票价 × 赠送瓶数）
3. **开票总值 V** ＝ 拿货金额 + 赠送货值
4. **综合折扣率 r** ＝ P ÷ V
5. **某产品底价** ＝ 该产品开票价 × r
6. **验算**：Σ（该产品到手总瓶数 × 底价） 是否等于 P

也就是：**客户付的钱，按各产品开票价的比例，平摊到客户实际拿到的每一瓶上**（拿货的 + 赠送的都算到手）。因此每个产品的折扣率相同，赠送越多底价越低。

### 算例

> 五年（6 瓶/箱，开票价 100 元/瓶）拿货 10 箱，赠送 6 瓶。

- 拿货金额 ＝ 100 × 6 × 10 ＝ **6,000 元**（客户付款 P）
- 赠送货值 ＝ 100 × 6 ＝ 600 元
- 开票总值 V ＝ 6,600 元
- 综合折扣率 r ＝ 6,000 ÷ 6,600 ＝ 0.909091
- 底价 ＝ 100 × 0.909091 ＝ **90.91 元/瓶**
- 验算：66 瓶 × 90.91 ＝ 6,000.06 元，与 6,000 元差 6 分 → ✅ 通过（尾差 0.06 ＜ 允许尾差 0.33）

### 关于「尾差」

底价按 2 位小数报价时，`瓶数 × 底价` 不可能总是刚好等于付款金额，这是四舍五入的必然结果。
程序按 **允许尾差 ＝ 0.5 ×（最低位单位）× 总瓶数** 来判断：

- 差额为 0 → ✅ 验算通过（完全一致）
- 差额在允许尾差内 → ⚠️ 验算通过（含尾差），并显示具体差额
- 超出允许尾差 → ❌ 验算不通过（说明录入数据有问题）

想让验算**完全为零**，把「产品底价」右上角切成 **4 位** 即可（底价会显示为 90.9091 这类精确值）。

## 四、数据与备份

- 产品库、计算记录、当前草稿都存在本机浏览器里，**不上传任何服务器**。
- 换手机、换浏览器、清理浏览器数据都会导致数据丢失，重要数据请点「产品库 → 导出全部数据」保存 JSON 备份，需要时用「导入数据」恢复。
- 记录里保存的是当时的**价格快照**：以后修改产品库的开票价，不会改变已保存的历史记录。

## 六、使用小贴士

- **发给客户**：点「生成对账单长图」出图 → 点「分享文案」选一段复制 → 两者一起发出去，客户一眼看清底价和付款。
- **金额不想手算？** 打开「手动指定付款金额」后会出现「算式计算」框，直接敲算式，例如
  `600x97%÷(600+130)x130` → 点「＝ 计算」→ 得到 **103.644** 并自动填进付款金额，底价与验算同步重算。
  - 支持 `+ − × ÷`、括号 `( )`、百分号 `%`（`97%` 就是 `0.97`）；`x`、`X`、`·` 都当乘号，`÷`、`/` 都当除号，中英文括号和 `＝` 前缀都能识别
  - 手机键盘打不出 `× ÷ ( ) %`？下面有一排小快捷键（`＋ − × ÷ ( ) % ⌫`），点一下插到光标处，`⌫` 删除
  - 结果最多显示 3 位小数（去掉多余的 0），后面括号里会给完整值；算式非法会红字提示，不会动你已经填好的金额
  - 算式会随草稿和记录一起保存，下次打开还在
- **数量快改**：拿货箱数、赠送瓶数右侧都有 ▲▼ 按钮，点一下 ±1，**按住不放可连续增减**（每 80ms 一次），不用反复点；数量最少减到 0，不会变负数。
- 产品库已预置示例产品（五年 / 六年 / 十年 / 二十年 / 十年礼盒 / 5斤臻品 / 2斤五年），请按你的实际开票价增删改；度数、容量可留空。
- 产品库支持批量导入，格式：`名称, 规格, 开票价, 度数, 容量`（逗号或空格分隔，逗号后 3 项可省略）。
- 遇到抹零、返利、政策扣减，打开「手动指定付款金额」填实际收款数，底价会跟着重算。
- 发给客户对账时：点「生成对账单长图」→「分享」直接发微信，或「保存图片」后从相册发送；也可以点「复制文本」发纯文字版。
